# Codex Prompt: Issue To Repo

Take the output of a Linear issue, business note, or research draft and convert it into organized Agri-AI repository documentation.

## Instructions

1. Identify the core idea or decision in the source material.
2. Decide where it belongs in the repo.
3. Update the existing file if one already covers that topic.
4. Create a new file only if the topic is distinct and durable.
5. Rewrite the content into concise markdown.
6. Remove noise, repetition, and temporary thinking.
7. Flag any unresolved items that should become new issues.

## Placement Guide

- venture framing -> `docs/business/venture_overview.md`
- deeper business reasoning -> `docs/business/business_analysis.md`
- pilot execution -> `docs/pilot/indiana_pilot.md`
- product boundaries -> `docs/product/mvp_scope.md`
- market and competitor findings -> `docs/research/`
- workflow mechanics -> `linear/` or `prompts/`

## Output Standard

- concise
- structured
- useful later
- easy to review
- clearly placed in the right file

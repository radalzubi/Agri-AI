# Module Specs

## A. Control Tower

- Purpose: the primary command center for weekly planning review
- Target users: supply planner, aggregator manager, executive
- Primary layout:
  - context bar
  - KPI strip
  - action board
  - exposure heatmap
  - insight rail
- Key components:
  - weighted coverage
  - demand at risk
  - overage exposure
  - shortage queue
  - overage watch
  - action queue
  - crop-week focus detail
  - memo highlights
  - trust status
- Filters:
  - season
  - crop
  - week range
  - role lens
- Primary actions:
  - focus a crop-week
  - open supporting queue
  - shift into Planning or Demand for deeper review
- Alerts:
  - shortage-first
  - trust blockers inline
- Permissions:
  - broad read access
- MVP:
  - full module ships now
- Later:
  - recent changes
  - scenarios
  - approvals
  - weather watch

## B. Planning

- Purpose: turn exposure into commitment posture
- Target users: supply planner, aggregator manager
- Primary layout:
  - planning posture summary
  - commit-now queue
  - rebalance queue
  - focus crop-week detail
  - crop summary
- Key components:
  - posture buckets:
    - `Commit now`
    - `Rebalance`
    - `Monitor`
  - shortage queue
  - overage watch
  - derived recommendations
- Tables:
  - crop summary
  - crop-week detail table
- Charts:
  - supporting weekly balance by selected crop
- Filters:
  - crop
  - week range
- Drill-down:
  - planning posture -> crop-week detail
  - crop summary -> weekly detail
- Alerts:
  - high shortage coverage gaps
  - high commercial overage
- Permissions:
  - planners and managers
- MVP:
  - heuristic planning workspace only
- Later:
  - editable production plan lines
  - scenario compare
  - approvals

## C. Demand

- Purpose: explain demand shape and coverage by crop-week
- Target users: supply planner, buyer/account manager, executive
- Primary layout:
  - selected crop analytical chart
  - crop summary table
  - weekly balance trend
  - crop-week imbalance table
- Key components:
  - crop selector
  - focus week selector
  - demand vs supply chart
  - crop totals and risk weeks
- Tables:
  - crop summary
  - selected crop weekly imbalance
- Charts:
  - selected crop demand vs supply
  - whole-season weekly balance
- Filters:
  - season
  - crop
  - week range
- Drill-down:
  - crop summary -> crop detail
  - week point -> crop-week detail
- Alerts:
  - selected crop shortage concentration
- Permissions:
  - broad read access
- MVP:
  - crop-level demand understanding only
- Later:
  - buyer/account patterns
  - forecast versioning
  - demand confidence inputs

## D. Operations

- Purpose: support weekly operating review and handoff
- Target users: aggregator manager, ops manager, executive
- Primary layout:
  - review summary
  - memo
  - action handoff
  - output readiness
- Key components:
  - weekly memo
  - action queue
  - review-pack summary
  - data run readiness
- Tables:
  - top shortage and overage tables
  - output file status
- Charts:
  - keep minimal; use only heatmap and one trend where useful
- Filters:
  - season
  - crop
  - week range
- Drill-down:
  - memo bullet -> supporting queue
  - readiness issue -> Admin or Intelligence
- Alerts:
  - stale output
  - unresolved blocker count
- Permissions:
  - broad read access
- MVP:
  - review-and-handoff only
- Later:
  - live execution signals
  - harvest readiness
  - logistics exceptions

## E. Intelligence

- Purpose: centralize exception analysis and trust review
- Target users: supply planner, data steward, executive
- Primary layout:
  - trust summary
  - risk register
  - unresolved blocker panel
  - supporting confidence detail
- Key components:
  - risk register
  - unresolved SKU summary
  - file freshness
  - trust impact notes
- Tables:
  - risk register
  - unresolved SKUs
  - output readiness
- Charts:
  - optional severity distribution by week
- Filters:
  - risk only
  - crop
  - week range
- Drill-down:
  - blocker -> affected week
  - risk row -> crop-week detail
- Alerts:
  - unresolved inputs
  - stale outputs
- Permissions:
  - broad read access
- MVP:
  - full module ships now
- Later:
  - anomaly detection
  - weather/disruption feed
  - richer confidence scoring

## F. Admin

- Purpose: keep the local command center understandable and operable
- Target users: data steward, founder/operator, admin
- Primary layout:
  - run status
  - thresholds
  - data contract
  - glossary
- Key components:
  - file status
  - output directory guidance
  - threshold assumptions
  - known MVP limits
- Tables:
  - output file readiness
- Filters:
  - none beyond output directory
- Drill-down:
  - file status -> readiness detail
- Alerts:
  - missing outputs
  - stale outputs
- Permissions:
  - broad read access
- MVP:
  - thin utility module
- Later:
  - role management
  - import diagnostics
  - threshold editing UI
